[업무 공략 036~039] 발표 준비 자료
발표 주제: 사내 메신저 교체 제안 (현재 3개 메신저 혼용 → 통합 협업 메신저 1개로)
발표자: 경영지원팀 IT기획 담당 / 청중: 경영진 회의 (발표 10분)

1. 현황
- 현재 사용 중인 메신저: 사내 구형 메신저(2015년 도입), 개인 카카오톡, 이메일 → 3개 혼용
- 구형 메신저 유지보수 계약: 2025년 12월 종료 예정 (연장 시 연 4,200만 원)
- 구형 메신저 모바일 미지원, 파일 전송 한도 20MB

2. 문제점 (2024년 10월 직원 설문, 응답 312명)
- "업무 대화를 찾느라 시간을 허비한다": 74% (1인당 하루 평균 23분)
- "개인 메신저로 업무 파일을 주고받은 적 있다": 81% → 보안 위험
- "퇴근 후 개인 메신저 업무 연락으로 스트레스": 62%
- 부서 간 협업 만족도: 5점 만점 2.7점

3. 대안 비교 (3개 솔루션 검토 결과 1개 추천)
- 추천 솔루션: 통합 협업 메신저 X (메신저 + 화상회의 + 파일 공유 + 업무 관리)
- 비용: 1인당 월 6,000원 × 420명 = 연 3,024만 원 (구형 유지보수 대비 연 1,176만 원 절감)
- 보안: 국내 클라우드 보안 인증(CSAP) 보유, 관리자 파일 반출 통제 가능
- 모바일/PC 모두 지원, 근무시간 외 알림 차단 기능

4. 기대 효과
- 대화 검색 시간 50% 감소 가정 → 1인당 하루 11.5분 절약
  → 420명 × 11.5분 × 연 240일 = 연 약 19,320시간
- 개인 메신저 업무 사용 차단으로 정보 유출 위험 감소
- 직원 만족도 향상 (워라밸)

5. 추진 일정 (안)
- 2025년 7월: 계약 및 환경 구성
- 8월: 파일럿 (IT기획팀, 영업2팀, 인사팀 60명)
- 9~10월: 전사 확대 및 교육
- 11월: 구형 메신저 데이터 이관 후 종료

6. 리스크
- 초기 사용 거부감 → 부서별 챔피언 지정, 사용 가이드 배포
- 데이터 이관 누락 → 이관 전 백업 및 2주 병행 운영
